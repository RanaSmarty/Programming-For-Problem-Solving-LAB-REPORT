# Looping Statement in C Programming Language

## Introduction

Looping statements are control-flow statements in the C programming language that allow a program to execute a block of code repeatedly as long as a specified condition is satisfied or for a predetermined number of iterations.

Looping statements help programmers reduce code repetition, automate repetitive tasks, and develop efficient solutions to programming problems.

C provides three primary looping statements: `for`, `while`, and `do-while`. Each loop has its own structure and is suitable for different programming problems.

This topic demonstrates the use of these looping statements through practical C programming experiments.

## Concepts Covered

1. **For Loop**
The `for` loop is commonly used when the number of iterations is known in advance. It combines initialization, condition checking, and updating in a single statement.

2. **While Loop**
The `while` loop repeatedly executes a block of code as long as its specified condition remains true. The condition is checked before each iteration, so the loop may executes zero times.

3. **Do-While Loop**
The `do-while` loop executes its block of code before checking the condition. Therefore, the loop body executes at least once, regardless of whether the condition is initially true or false.

## Components Used

- **Initialization:** Establishes the starting value of a loop-control variable.
- **Condition:** Determines whether the loop should continue executing.
- **Update:** Changes the loop-control variable to help the loop progress toward termination.
- **Increment Operator:** `++` increases a variable's value by one.
- **Decrement Operator:** `--` decreases a variable's value by one.
- **Relational Operator:** `>`, `<`, `<=`, `>=`, `==`, and `!=` can be used to construct loop conditions.
- **Assignment Operator:** `=` assigns a value to a variable.
