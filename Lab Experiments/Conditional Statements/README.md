# Conditional Statements in C Programming Language

## Introduction

**Conditional statements are decision-making statements in the C programming language. They allow a program to execute different blocks of code depending on whether specified conditions are true of false.

Conditional statements helps programmers control the flow of a program and make decisions based on user input or other values.

This topic demonstrates the use of `if-else` and `if-else-if` statements through practical C programming experiments.

## Objectives

- To understand the concept of conditional statements in C.
- To learn how to use `if-else` and `if-else-if` ladder statements.
- To apply logical and relational operators to evaluate conditions.
- To develop C programs that make decisions based on specified conditions.
- To improve problem-solving skills through practical programming exercises.

## Concepts Covered

1. **If-Else Statement**

The `if-else` statement allows a  program to choose between two alternative execution paths. If the specified condition is true, the `if` block executes; otherwise, the `else` block executes.

1. 2.**If-Else-If Statement**

The `if-else-if` statement allows a program to evaluate multiple conditions in sequence. The block associated with the first true condition executes. If none of the conditions is true, the final `else` block executes, if provided.

## Operators Used

- **Relational Operators:** `>`, `<`, `<=`, `>=`, `==`, and `!=`
- **Logical Operators:** `&&`, `||`, and `!`
